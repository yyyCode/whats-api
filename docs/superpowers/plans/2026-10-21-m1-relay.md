# M1 转发闭环实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一次 OpenAI 兼容的 `POST /v1/chat/completions` 能端到端跑通，流式可用、失败能换渠道、客户端断开能停上游。

**Architecture:** 在 M0 骨架上加三块：`internal/middleware/auth.go`（Token 鉴权）、`internal/relay/*`（适配器 + SSE 转发）、`internal/controller/relay.go`（主循环）。选渠道按「最高优先级档 + 档内加权随机」直查 `channels` 表；**本阶段不做计费**（M2）、不做管理 API（M3）、不做 Ability 反范式索引（M4）。

**Tech Stack:** Go 1.23、gin v1.11.0、GORM、标准库 `net/http` / `bufio`。不新增任何第三方依赖。

## 0. 拍板记录（本阶段偏离设计文档的地方）

| 决策 | 取值 | 理由 |
|---|---|---|
| 转发端点 | 只做 `POST /v1/chat/completions` | M1 的目标就是一条链路；别的端点等 M2/M3 |
| 协议 | 只做 OpenAI 兼容（`channels.type = 1`） | 协议互转是 M6 的触发项 |
| 选渠道的位置 | 在 `controller.Relay` 的重试循环里调用 `service.SelectChannel`，**不做 `middleware.Distribute`** | 重试本来就要重选；放在中间件里会把 body 解析和选路各做两遍。等 M3 有更细的中间件需求再搬 |
| 鉴权读取 body 吗 | 不读；模型白名单在 handler 解析出 `model` 之后校验 | 少一次 body 解析；被拒请求的代价同样低 |
| 候选集来源 | 直查 `channels` 表，解析 `models` CSV | `abilities` 反范式索引是 M4；M1 数据量小，直查正确性更容易看住 |
| 重试判定 | 5xx / 429 / 传输错误可重试；**开流后一律不重试**；**自动禁用只对 5xx** | 03 篇 §7 的硬约束；429 是上游限流，换渠道有意义，但当故障禁用会放大事故 |
| 自动禁用 | 条件 UPDATE：`status=enabled → auto_disabled` | 手动禁用的渠道绝不能被自动改写（`constant` 里已定义两种禁用态） |
| 模型映射 | `Channel.ModelMapping` 解析成 `map[string]string`；未命中则用原模型名 | M3 的配置字段提前落地，成本只有十几行 |
| 保活间隔 | 默认 10s，放在 `RelayInfo.Stream.PingInterval` 里 | 做成字段是为了测试能用 50ms 的间隔观察 ping，而不是等 10 秒 |
| 计费 | **不做**。`usage` 目前解析后丢弃 | M2 的整个主题；M1 的 `DoResponse` 已经按「返回 usage」的形状留好接口 |
| 请求体解压 | 不支持 gzip | 与 `02` 篇的 `DecompressRequestMiddleware` 一起在 M3 前补 |
| 版本号 | `v0.2.0-m1` | 里程碑可观察 |

```go
// Package types 存放跨层共享的转发面类型。
//
// M1 只有一种：统一错误。它的价值在于把三件事绑在一起——
// 给客户端看的形状、给控制流用的可重试标志、给日志用的可读描述。
// 绝不拿错误字符串做控制流：重试与自动禁用只读这里的两个布尔值。
package types

import (
	"fmt"
	"net/http"

	"github.com/gin-gonic/gin"
)

// APIError 是转发面唯一的错误类型。
type APIError struct {
	// StatusCode 是写给客户端的 HTTP 状态码；0 表示"不要写"（客户端已断开）。
	StatusCode int
	Message    string
	Type       string
	Code       string

	// Retryable 表示"还没向客户端写出任何字节时，值得换一个渠道再试"。
	Retryable bool
	// ChannelError 表示错误归因于渠道，可以自动禁用。
	ChannelError bool
}

func (e *APIError) Error() string {
	return fmt.Sprintf("%s (status=%d type=%s code=%s)", e.Message, e.StatusCode, e.Type, e.Code)
}

// Write 按 OpenAI 的错误形状写给客户端。
func (e *APIError) Write(c *gin.Context) {
	if e == nil || e.StatusCode == 0 {
		return
	}
	c.JSON(e.StatusCode, gin.H{"error": gin.H{
		"message": e.Message,
		"type":    e.Type,
		"code":    e.Code,
	}})
}

// NewBadRequest 用于请求本身的问题（缺字段、JSON 非法、请求过大）。
func NewBadRequest(message string) *APIError {
	return &APIError{
		StatusCode: http.StatusBadRequest,
		Message:    message,
		Type:       "invalid_request_error",
		Code:       "invalid_request",
	}
}

// NewRequestTooLarge 单独一个构造函数：状态码不同（413），且调用方要能一眼看出。
func NewRequestTooLarge() *APIError {
	return &APIError{
		StatusCode: http.StatusRequestEntityTooLarge,
		Message:    "请求体过大",
		Type:       "invalid_request_error",
		Code:       "request_too_large",
	}
}

// NewAuthenticationError：没有令牌、令牌无效/停用/过期、用户不存在。
func NewAuthenticationError(message string) *APIError {
	return &APIError{
		StatusCode: http.StatusUnauthorized,
		Message:    message,
		Type:       "authentication_error",
		Code:       "invalid_api_key",
	}
}

// NewPermissionError：令牌有效，但不能做这件事（模型不在白名单、用户被停用）。
func NewPermissionError(message string) *APIError {
	return &APIError{
		StatusCode: http.StatusForbidden,
		Message:    message,
		Type:       "permission_error",
		Code:       "permission_denied",
	}
}

// NewQuotaError 对应 OpenAI 的 insufficient_quota。
func NewQuotaError(message string) *APIError {
	return &APIError{
		StatusCode: http.StatusForbidden,
		Message:    message,
		Type:       "insufficient_quota",
		Code:       "insufficient_quota",
	}
}

// NewNoChannelError：分组不匹配或该模型没有可用渠道。
// 503 而不是 404：这是"暂时没有可用的上游"，不是"这个模型永远不存在"。
func NewNoChannelError(modelName string) *APIError {
	return &APIError{
		StatusCode: http.StatusServiceUnavailable,
		Message:    fmt.Sprintf("模型 %q 当前没有可用渠道", modelName),
		Type:       "server_error",
		Code:       "no_channel",
	}
}

// NewUpstreamError 保留上游状态码，并按状态码判定是否值得重试：
// 5xx 与 429 归因于渠道；其余 4xx 是请求本身的问题，重试只会放大故障。
func NewUpstreamError(status int, message string) *APIError {
	if status < 400 || status > 599 {
		status = http.StatusBadGateway
	}
	retryable := status == http.StatusTooManyRequests || status >= 500
	return &APIError{
		StatusCode:   status,
		Message:      message,
		Type:         "upstream_error",
		Code:         "upstream_error",
		Retryable:    retryable,
		ChannelError: retryable,
	}
}

// NewTransportError：连不上、DNS 失败、响应头超时。归因于渠道。
func NewTransportError(message string) *APIError {
	return &APIError{
		StatusCode:   http.StatusBadGateway,
		Message:      message,
		Type:         "upstream_error",
		Code:         "upstream_unreachable",
		Retryable:    true,
		ChannelError: true,
	}
}

// NewInternalError：网关自身的故障（配置没有适配器、查库失败）。
func NewInternalError(message string) *APIError {
	return &APIError{
		StatusCode: http.StatusInternalServerError,
		Message:    message,
		Type:       "server_error",
		Code:       "internal_error",
	}
}

// NewClientGone：客户端在流式过程中断开。
// StatusCode 为 0 —— 连接都没了，写响应既无意义也会掩盖真实原因。
func NewClientGone() *APIError {
	return &APIError{Message: "客户端已断开", Type: "client_gone", Code: "client_gone"}
}
```

```go
package model

import (
	"errors"

	"gorm.io/gorm"

	"github.com/yyyCode/whats-api/internal/constant"
)

// ErrNotFound 是"查了但没有"的统一哨兵。
// 调用方必须能区分它与数据库故障：前者是 401，后者是 500。
var ErrNotFound = errors.New("记录不存在")

// db 返回主库句柄。每个查询都先过这一道：
// 初始化早期的 nil 句柄应该给出明确错误，而不是在 GORM 内部空指针崩溃。
func db() (*gorm.DB, error) {
	if DB == nil {
		return nil, errors.New("主库未初始化")
	}
	return DB, nil
}

// GetTokenByKey 按明文 key 查令牌。M1 直接查库（key 上有唯一索引），缓存是 M3 的事。
func GetTokenByKey(key string) (*Token, error) {
	d, err := db()
	if err != nil {
		return nil, err
	}
	var tok Token
	// key 是 MySQL/PG/SQLite 的保留字，必须经方言 helper 加引号。
	if err := d.Where(commonKeyCol()+" = ?", key).First(&tok).Error; err != nil {
		if errors.Is(err, gorm.ErrRecordNotFound) {
			return nil, ErrNotFound
		}
		return nil, err
	}
	return &tok, nil
}

// GetUserByID 查令牌所属用户。
func GetUserByID(id int) (*User, error) {
	d, err := db()
	if err != nil {
		return nil, err
	}
	var u User
	if err := d.First(&u, id).Error; err != nil {
		if errors.Is(err, gorm.ErrRecordNotFound) {
			return nil, ErrNotFound
		}
		return nil, err
	}
	return &u, nil
}

// GetEnabledChannels 取全部启用中的渠道。选路的过滤（分组/模型/排除）在 service 层做，
// 这样"查什么"与"怎么选"分开，选路逻辑可以脱离数据库单测。
func GetEnabledChannels() ([]Channel, error) {
	d, err := db()
	if err != nil {
		return nil, err
	}
	var channels []Channel
	if err := d.Where("status = ?", constant.ChannelStatusEnabled).Find(&channels).Error; err != nil {
		return nil, err
	}
	return channels, nil
}

// DisableChannel 把启用中的渠道置为自动禁用。
//
// 条件里必须带 status = enabled：手动禁用的渠道不能被自动化改写，
// 否则 M4 的"只恢复自动禁用的"就失去了判断依据。返回是否真的改写了。
func DisableChannel(id int) (bool, error) {
	d, err := db()
	if err != nil {
		return false, err
	}
	res := d.Model(&Channel{}).
		Where("id = ? AND status = ?", id, constant.ChannelStatusEnabled).
		Update("status", constant.ChannelStatusAutoDisabled)
	if res.Error != nil {
		return false, res.Error
	}
	return res.RowsAffected > 0, nil
}

// TouchTokenAccessed 记录令牌最近使用时间。
// 鉴权中间件按分钟节流调用它——SQLite 是单写者，每个请求写一次会把并发串行化。
func TouchTokenAccessed(id int, ts int64) error {
	d, err := db()
	if err != nil {
		return err
	}
	return d.Model(&Token{}).Where("id = ?", id).Update("accessed_at", ts).Error
}
```

```go
// Package service 是业务逻辑层：选渠道、自动禁用等。
//
// 这一层不碰 HTTP——入参是普通值，出参是 model 与 types，
// 于是它可以在没有 gin、没有数据库连接的测试里被直接验证。
package service

import (
	"math/rand"
	"strings"

	"github.com/yyyCode/whats-api/internal/constant"
	"github.com/yyyCode/whats-api/internal/model"
	"github.com/yyyCode/whats-api/internal/types"
)

// DefaultGroup 是分组为空时的归一化值。
// 令牌/用户/渠道三处都按它归一化，避免"空串 vs default"这种配置陷阱。
const DefaultGroup = "default"

func NormalizeGroup(g string) string {
	if g = strings.TrimSpace(g); g == "" {
		return DefaultGroup
	}
	return g
}

// SelectChannel 选一个渠道；exclude 是本次请求已经试过（含刚失败）的渠道 ID。
//
// 直查数据库而不是走缓存：M1 的数据量与并发都不值得引入缓存失效问题；
// 缓存 + 反范式索引是 M4 的主题。
func SelectChannel(group, modelName string, exclude map[int]bool) (*model.Channel, *types.APIError) {
	channels, err := model.GetEnabledChannels()
	if err != nil {
		return nil, types.NewInternalError("查询渠道失败: " + err.Error())
	}

	candidates := filterChannels(channels, group, modelName, exclude)
	if len(candidates) == 0 {
		return nil, types.NewNoChannelError(modelName)
	}
	return pickChannel(candidates, rand.Float64()), nil
}

// filterChannels 是纯函数：分组（空=default）、模型清单、排除集、启用态四重过滤。
// 启用态在 SQL 里已经过滤过，这里再判一次是防御——调用方可能传入全表。
func filterChannels(channels []model.Channel, group, modelName string, exclude map[int]bool) []model.Channel {
	g := NormalizeGroup(group)
	out := make([]model.Channel, 0, len(channels))
	for _, ch := range channels {
		if exclude[ch.ID] {
			continue
		}
		if ch.Status != constant.ChannelStatusEnabled {
			continue
		}
		if NormalizeGroup(ch.GroupName) != g {
			continue
		}
		if !modelListContains(ch.Models, modelName) {
			continue
		}
		out = append(out, ch)
	}
	return out
}

// modelListContains 按逗号切分并去空白，精确匹配（不做前缀匹配）。
func modelListContains(models, modelName string) bool {
	for _, m := range strings.Split(models, ",") {
		if strings.TrimSpace(m) == modelName {
			return true
		}
	}
	return false
}

// pickChannel：先取最高优先级那一档，再在档内按权重随机；权重全为 0 时均匀随机。
//
// r 是 [0,1) 的随机数，做成参数是为了让分布能被确定性测试——
// 直接调 rand 会让"选中了哪个"只能靠统计，测试既不稳也不快。
func pickChannel(channels []model.Channel, r float64) *model.Channel {
	top := channels[0].Priority
	for _, ch := range channels[1:] {
		if ch.Priority > top {
			top = ch.Priority
		}
	}

	tier := make([]model.Channel, 0, len(channels))
	for _, ch := range channels {
		if ch.Priority == top {
			tier = append(tier, ch)
		}
	}
	if len(tier) == 1 {
		ch := tier[0]
		return &ch
	}

	var total uint64
	for _, ch := range tier {
		total += uint64(ch.Weight)
	}

	// 全 0 权重是合法配置（例如刚建好的渠道）：均匀分布，
	// 既不能 panic，也不能一个都选不出来。
	if total == 0 {
		i := int(r * float64(len(tier)))
		if i >= len(tier) {
			i = len(tier) - 1
		}
		ch := tier[i]
		return &ch
	}

	target := r * float64(total)
	var acc float64
	for i := range tier {
		acc += float64(tier[i].Weight)
		if target < acc {
			ch := tier[i]
			return &ch
		}
	}
	ch := tier[len(tier)-1]
	return &ch
}
```

```go
// Package relaycommon 是转发内核的请求上下文。
//
// ★ 核心纪律：状态显式分成 RequestState（跨尝试共享）与 AttemptState（每次重置）。
// 重试时清错一边的后果都很严重：清了 RequestState 会重复扣费/丢身份，
// 不清 AttemptState 会把上一个渠道的密钥、模型映射和写出的字节数带到下一个渠道。
package relaycommon

import (
	"time"

	"github.com/gin-gonic/gin"

	"github.com/yyyCode/whats-api/internal/types"
)

// DefaultPingInterval 是流式保活间隔。
// 中间的 Nginx/负载均衡通常 60s 无数据就断；10s 留出足够余量。
const DefaultPingInterval = 10 * time.Second

// AuthInfo 由鉴权中间件填充，handler 只读。
type AuthInfo struct {
	TokenID        int
	UserID         int
	TokenName      string
	Group          string
	UnlimitedQuota bool

	ModelLimitsEnabled bool
	ModelLimits        string
}

// gin.Context 的键。全部经本文件读写，不让字符串字面量散落在各层。
const (
	ContextKeyAuth      = "relay_auth"
	ContextKeyRequestID = "relay_request_id"
)

func SetAuthInfo(c *gin.Context, a *AuthInfo) { c.Set(ContextKeyAuth, a) }

func GetAuthInfo(c *gin.Context) *AuthInfo {
	if v, ok := c.Get(ContextKeyAuth); ok {
		if a, ok := v.(*AuthInfo); ok {
			return a
		}
	}
	return nil
}

// RequestPayload 是转发面需要从请求体读出的少数几个字段。
// 其余字段不解析——M1 是透传，解析得越少，丢字段/改形状的风险越小。
type RequestPayload struct {
	Model  string `json:"model"`
	Stream bool   `json:"stream"`
}

// RequestState 跨尝试共享：身份、原始请求体、模型名、重试计数、最后一个错误。
type RequestState struct {
	RequestID       string
	TokenID         int
	UserID          int
	Group           string
	OriginModelName string
	IsStream        bool
	Body            []byte
	RetryIndex      int
	LastError       *types.APIError
}

// ChannelMeta 描述"这一次尝试选中的渠道"。
type ChannelMeta struct {
	ChannelID         int
	ChannelType       int
	ChannelName       string
	BaseURL           string
	APIKey            string
	UpstreamModelName string
	ModelMapped       bool
}

// AttemptState 每次尝试重置。
//
// ResponseWritten > 0 是"不能再重试"的唯一判据：客户端已经收到字节，
// 再接一段来自另一个渠道的内容就是错乱。流式请求在响应头发出时就置位。
type AttemptState struct {
	ChannelMeta
	ResponseWritten int64
	UpstreamStatus  int
}

// StreamOptions 控制流式转发的时钟。做成字段而不是常量，
// 测试才能用 50ms 的保活间隔观察 ping。
type StreamOptions struct {
	PingInterval time.Duration
}

// RelayInfo 是一整次请求的上下文。
type RelayInfo struct {
	Request RequestState
	Attempt AttemptState
	Stream  StreamOptions
}

func GenRelayInfo(auth *AuthInfo, payload *RequestPayload, requestID string, body []byte) *RelayInfo {
	return &RelayInfo{
		Request: RequestState{
			RequestID:       requestID,
			TokenID:         auth.TokenID,
			UserID:          auth.UserID,
			Group:           auth.Group,
			OriginModelName: payload.Model,
			IsStream:        payload.Stream,
			Body:            body,
		},
		Stream: StreamOptions{PingInterval: DefaultPingInterval},
	}
}

// ResetAttempt 换渠道/重试时调用：只重置每次尝试的状态。
func (i *RelayInfo) ResetAttempt(meta ChannelMeta) {
	i.Attempt = AttemptState{ChannelMeta: meta}
}

// AddResponseWritten 累计已经写给客户端的字节数。
func (i *RelayInfo) AddResponseWritten(n int) {
	if n > 0 {
		i.Attempt.ResponseWritten += int64(n)
	}
}

func (i *RelayInfo) WroteResponse() bool { return i.Attempt.ResponseWritten > 0 }
```

```go
// Package channel 定义上游适配器接口与所有适配器共用的出站传输。
//
// 适配器只做四件事：转换请求、算出 URL、拼认证头、解析响应。
// 它不读数据库、不读全局配置、不算钱——需要什么由 RelayInfo 传入。
package channel

import (
	"io"
	"net"
	"net/http"
	"time"

	"github.com/gin-gonic/gin"

	relaycommon "github.com/yyyCode/whats-api/internal/relay/common"
	"github.com/yyyCode/whats-api/internal/types"
)

// Adaptor 是一个上游供应商的实现。
//
// M1 只做 Chat Completions，所以接口只有一条转换路径；
// 协议互转（Claude/Gemini）在 M6 触发，届时按 03 篇扩展成一组 Convert*。
type Adaptor interface {
	// Init 每次尝试开始时调用（重试会重新调用）。
	Init(info *relaycommon.RelayInfo)

	// ConvertRequest 下游 OpenAI 请求 → 上游请求。M1 是透传 + 模型映射。
	ConvertRequest(c *gin.Context, info *relaycommon.RelayInfo, requestBody []byte) ([]byte, error)

	// GetRequestURL 与 SetupRequestHeader 负责定位与认证。
	GetRequestURL(info *relaycommon.RelayInfo) (string, error)
	SetupRequestHeader(c *gin.Context, header *http.Header, info *relaycommon.RelayInfo) error

	// DoRequest 发 HTTP。绝大多数实现直接复用 DoApiRequest。
	DoRequest(c *gin.Context, info *relaycommon.RelayInfo, body io.Reader) (*http.Response, error)

	// DoResponse 读上游响应、转发给客户端、返回 usage 供计费（M1 丢弃 usage）。
	DoResponse(c *gin.Context, resp *http.Response, info *relaycommon.RelayInfo) (usage any, err *types.APIError)

	GetChannelName() string
}

// sharedClient 是所有适配器共用的出站客户端。
//
// ★ 刻意不设 Client.Timeout：SSE 响应可能持续几分钟，总超时会把正常的流掐断。
// 用 ResponseHeaderTimeout 卡住"上游一直不回响应头"，用拨号超时卡住"连不上"。
var sharedClient = &http.Client{
	Transport: &http.Transport{
		Proxy: http.ProxyFromEnvironment,
		DialContext: (&net.Dialer{
			Timeout:   10 * time.Second,
			KeepAlive: 30 * time.Second,
		}).DialContext,
		MaxIdleConns:          100,
		MaxIdleConnsPerHost:   20,
		IdleConnTimeout:       90 * time.Second,
		TLSHandshakeTimeout:   10 * time.Second,
		ResponseHeaderTimeout: 60 * time.Second,
		ForceAttemptHTTP2:     true,
	},
}

// DoApiRequest 是所有适配器共用的 POST 实现。
//
// ★ 请求绑定 c.Request.Context()：客户端断开时，上游请求会被一起取消。
// 这是"客户端走了就别继续烧 token"的第一道保障，不需要额外的心跳检测。
func DoApiRequest(a Adaptor, c *gin.Context, info *relaycommon.RelayInfo, body io.Reader) (*http.Response, error) {
	url, err := a.GetRequestURL(info)
	if err != nil {
		return nil, err
	}
	req, err := http.NewRequestWithContext(c.Request.Context(), http.MethodPost, url, body)
	if err != nil {
		return nil, err
	}
	if err := a.SetupRequestHeader(c, &req.Header, info); err != nil {
		return nil, err
	}
	return sharedClient.Do(req)
}
```

```go
import (
	"strings"

	"github.com/yyyCode/whats-api/internal/common"
	"github.com/yyyCode/whats-api/internal/logger"

// MapModel 应用渠道的模型映射（channels.model_mapping，形如 {"客户端名":"上游名"}）。
//
// 映射是"可选优化"而不是"必须正确"：JSON 坏了就按原模型名转发并告警，
// 因为拒绝整个请求的代价远大于一次映射失效。
func MapModel(originModel, mappingJSON string) (string, bool) {
	if strings.TrimSpace(mappingJSON) == "" {
		return originModel, false
	}
	var mapping map[string]string
	if err := common.UnmarshalString(mappingJSON, &mapping); err != nil {
		logger.Warn("渠道 model_mapping 不是合法 JSON，按原模型名转发", "error", err)
		return originModel, false
	}
	if upstream, ok := mapping[originModel]; ok && strings.TrimSpace(upstream) != "" {
		return upstream, true
	}
	return originModel, false
}
```

```go
package helper

import (
	"bufio"
	"errors"
	"io"
	"net/http"
	"strings"
	"time"

	"github.com/gin-gonic/gin"

	"github.com/yyyCode/whats-api/internal/logger"
	relaycommon "github.com/yyyCode/whats-api/internal/relay/common"
	"github.com/yyyCode/whats-api/internal/types"
)

const (
	// maxSSELineBytes：单个 SSE 行可以很大（长 token、base64 图片），
	// bufio.Scanner 默认 64KB 上限会在这种请求上直接报 "token too long"。
	maxSSELineBytes = 1 << 20
	// streamChanSize 是读/写两个 goroutine 之间的缓冲。
	// 有缓冲才能在客户端慢一拍时继续读上游，而不是把上游连接也卡住。
	streamChanSize = 64
)

type streamEvent struct {
	data string
	err  error
}

// StreamScannerHandler 把上游 SSE 逐事件转发给客户端。
//
// 为什么读与写必须是两个 goroutine：流式转发同时受三个时钟约束——
// 上游出数据的节奏、客户端读取的节奏、保活时钟。单 goroutine 在
// "上游 30 秒不出数据"时就无法感知客户端已经断开，上游的 token 会白烧。
//
// 返回值约定：
//   - nil：正常收到 [DONE]，或客户端主动断开（不写响应）
//   - 非 nil：上游流异常结束；此时 ResponseWritten 已置位，调用方不会写响应
func StreamScannerHandler(c *gin.Context, resp *http.Response, info *relaycommon.RelayInfo) *types.APIError {
	defer resp.Body.Close()

	setEventStreamHeaders(c)
	c.Writer.WriteHeaderNow()
	c.Writer.Flush()
	// 响应头已发出：从此刻起不能再换渠道，否则客户端会收到两段流。
	info.AddResponseWritten(1)

	pingInterval := info.Stream.PingInterval
	if pingInterval <= 0 {
		pingInterval = relaycommon.DefaultPingInterval
	}
	ticker := time.NewTicker(pingInterval)
	defer ticker.Stop()

	events := make(chan streamEvent, streamChanSize)
	stop := make(chan struct{})
	defer close(stop)

	go scanSSE(resp.Body, events, stop)

	sawDone := false
	for {
		select {
		case <-c.Request.Context().Done():
			// 客户端断开：不写任何东西，也不该禁用渠道。
			return nil

		case <-ticker.C:
			if _, err := c.Writer.WriteString(": keep-alive\n\n"); err != nil {
				return nil // 写不进去说明连接已断，等同客户端断开
			}
			c.Writer.Flush()

		case ev, ok := <-events:
			if !ok {
				if sawDone {
					return nil
				}
				return types.NewUpstreamError(http.StatusBadGateway, "上游流在 [DONE] 之前结束")
			}
			if ev.err != nil {
				logger.Warn("读取上游流失败", "channel_id", info.Attempt.ChannelID, "error", ev.err)
				return types.NewUpstreamError(http.StatusBadGateway, "读取上游流失败: "+ev.err.Error())
			}
			if ev.data == "[DONE]" {
				sawDone = true
			}
			n, err := c.Writer.WriteString("data: " + ev.data + "\n\n")
			info.AddResponseWritten(n)
			if err != nil {
				return nil
			}
			c.Writer.Flush()
			if sawDone {
				return nil
			}
		}
	}
}

func setEventStreamHeaders(c *gin.Context) {
	h := c.Writer.Header()
	h.Set("Content-Type", "text/event-stream; charset=utf-8")
	h.Set("Cache-Control", "no-cache")
	h.Set("Connection", "keep-alive")
	// 关掉 Nginx 的响应缓冲，否则事件会被攒着一起发，流式就名存实亡。
	h.Set("X-Accel-Buffering", "no")
}

// scanSSE 逐行读上游，只把 data 行送进 channel。
// OpenAI 的流只需要 data 行：event/id/comment 对我们没有语义。
func scanSSE(r io.Reader, events chan<- streamEvent, stop <-chan struct{}) {
	defer close(events)

	scanner := bufio.NewScanner(r)
	scanner.Buffer(make([]byte, 64*1024), maxSSELineBytes)

	for scanner.Scan() {
		line := scanner.Text()
		if !strings.HasPrefix(line, "data:") {
			continue
		}
		data := strings.TrimSpace(strings.TrimPrefix(line, "data:"))
		if data == "" {
			continue
		}
		select {
		case events <- streamEvent{data: data}:
		case <-stop:
			return
		}
	}

	if err := scanner.Err(); err != nil && !errors.Is(err, io.EOF) {
		select {
		case events <- streamEvent{err: err}:
		case <-stop:
		}
	}
}
```

```go
package middleware

import (
	"errors"
	"strings"
	"time"

	"github.com/gin-gonic/gin"

	"github.com/yyyCode/whats-api/internal/constant"
	"github.com/yyyCode/whats-api/internal/logger"
	"github.com/yyyCode/whats-api/internal/model"
	relaycommon "github.com/yyyCode/whats-api/internal/relay/common"
	"github.com/yyyCode/whats-api/internal/types"
)

// accessedAtThrottleSeconds：令牌最近使用时间的最小刷新间隔。
// 每个请求都写一次会让 SQLite 的单写者把并发请求串行化；
// 60 秒的精度对"这个令牌还活着吗"足够。
const accessedAtThrottleSeconds = 60

// TokenAuth 校验 Authorization: Bearer <key>，把身份写进 gin.Context。
//
// M1 直查数据库（令牌 key 有唯一索引）；缓存是 M3 的事。
// 模型白名单不在这里查：它需要请求体里的 model，由 handler 解析后校验。
func TokenAuth() gin.HandlerFunc {
	return func(c *gin.Context) {
		key := extractTokenKey(c)
		if key == "" {
			types.NewAuthenticationError("缺少 API Key（请使用 Authorization: Bearer <key>）").Write(c)
			c.Abort()
			return
		}

		token, err := model.GetTokenByKey(key)
		if err != nil {
			if errors.Is(err, model.ErrNotFound) {
				types.NewAuthenticationError("API Key 无效").Write(c)
			} else {
				logger.Error("查询令牌失败", "error", err)
				types.NewInternalError("鉴权服务暂时不可用").Write(c)
			}
			c.Abort()
			return
		}

		now := time.Now().Unix()
		switch {
		case token.Status != constant.TokenStatusEnabled:
			types.NewAuthenticationError("API Key 已被停用").Write(c)
			c.Abort()
			return
		case token.ExpiredTime != -1 && token.ExpiredTime < now:
			types.NewAuthenticationError("API Key 已过期").Write(c)
			c.Abort()
			return
		case !token.UnlimitedQuota && token.RemainQuota <= 0:
			types.NewQuotaError("API Key 额度已用尽").Write(c)
			c.Abort()
			return
		}

		user, err := model.GetUserByID(token.UserID)
		if err != nil {
			if errors.Is(err, model.ErrNotFound) {
				types.NewAuthenticationError("API Key 所属用户不存在").Write(c)
			} else {
				logger.Error("查询用户失败", "error", err)
				types.NewInternalError("鉴权服务暂时不可用").Write(c)
			}
			c.Abort()
			return
		}
		if user.Status != constant.UserStatusEnabled {
			types.NewPermissionError("用户已被停用").Write(c)
			c.Abort()
			return
		}

		group := token.GroupName
		if strings.TrimSpace(group) == "" {
			group = user.GroupName
		}

		relaycommon.SetAuthInfo(c, &relaycommon.AuthInfo{
			TokenID: token.ID,
			UserID:  token.UserID,
			// TokenName 留空：Token 模型还没有 name 列，而把明文 key 放进上下文
			// 只会给未来的日志埋一个泄漏点。
			Group:              group,
			UnlimitedQuota:     token.UnlimitedQuota,
			ModelLimitsEnabled: token.ModelLimitsEnabled,
			ModelLimits:        token.ModelLimits,
		})

		if now-token.AccessedAt >= accessedAtThrottleSeconds {
			if err := model.TouchTokenAccessed(token.ID, now); err != nil {
				// 使用时间刷新失败不影响鉴权结果：它是观测数据，不是正确性条件。
				logger.Warn("刷新令牌使用时间失败", "token_id", token.ID, "error", err)
			}
		}

		c.Next()
	}
}

// extractTokenKey 支持标准 Bearer 头，也接受裸 key 与 X-Api-Key（兼容各类 SDK）。
func extractTokenKey(c *gin.Context) string {
	if h := strings.TrimSpace(c.GetHeader("Authorization")); h != "" {
		if strings.HasPrefix(strings.ToLower(h), "bearer ") {
			return strings.TrimSpace(h[len("bearer "):])
		}
		return h
	}
	return strings.TrimSpace(c.GetHeader("X-Api-Key"))
}
```

> `TokenName` 目前用 key 填充：`Token` 模型没有 name 列（M0 的 DDL 精简了它）。
> 日志里展示 key 不安全——**M1 不要打印 TokenName**；M3 补 `name` 列后再改。

```go
		t.Fatalf("状态码 = %d", resp.StatusCode)
	}

	first, err := reader.ReadString('\n')
	if err != nil {

	if elapsed > 450*time.Millisecond {
```

```go
const (
	// maxRequestBodyBytes：多模态请求里的 base64 图片可以很大，
	// 32MB 是 OpenAI 同量级的上限。
	maxRequestBodyBytes = 32 << 20
	// maxRetryTimes 是换渠道的次数上限：总共最多 3 次尝试。
	// 再多只是在故障时放大负载——反模式清单里明确禁止"什么错误都重试"。
	maxRetryTimes = 2
)

// Relay 是转发主循环：解析 → 选渠道 → 转换 → 上游 → 响应；失败时换渠道重试。
func Relay(c *gin.Context) {
	auth := relaycommon.GetAuthInfo(c)
	if auth == nil {
		types.NewAuthenticationError("缺少鉴权信息").Write(c)
		return
	}

	body, apiErr := readRequestBody(c)
	if apiErr != nil {
		apiErr.Write(c)
		return
	}

	var payload relaycommon.RequestPayload
	if err := common.Unmarshal(body, &payload); err != nil {
		types.NewBadRequest("请求体必须是合法 JSON").Write(c)
		return
	}
	if strings.TrimSpace(payload.Model) == "" {
		types.NewBadRequest("缺少 model 字段").Write(c)
		return
	}
	if !modelAllowed(auth, payload.Model) {
		types.NewPermissionError(fmt.Sprintf("API Key 不允许使用模型 %q", payload.Model)).Write(c)
		return
	}

	info := relaycommon.GenRelayInfo(auth, &payload, middleware.GetRequestID(c), body)

	tried := make(map[int]bool, maxRetryTimes+1)
	var lastErr *types.APIError

	for attempt := 0; attempt <= maxRetryTimes; attempt++ {
		info.Request.RetryIndex = attempt

		ch, selectErr := service.SelectChannel(info.Request.Group, info.Request.OriginModelName, tried)
		if selectErr != nil {
			lastErr = selectErr
			break
		}
		tried[ch.ID] = true

		upstreamModel, mapped := helper.MapModel(info.Request.OriginModelName, ch.ModelMapping)
		info.ResetAttempt(relaycommon.ChannelMeta{
			ChannelID:         ch.ID,
			ChannelType:       ch.Type,
			ChannelName:       fmt.Sprintf("channel#%d", ch.ID),
			BaseURL:           ch.BaseURL,
			APIKey:            firstAPIKey(ch.Key),
			UpstreamModelName: upstreamModel,
			ModelMapped:       mapped,
		})

		adaptor := relay.GetAdaptor(ch.Type)
		if adaptor == nil {
			lastErr = types.NewInternalError(fmt.Sprintf("渠道类型 %d 尚未支持", ch.Type))
			logger.Error("渠道类型没有适配器", "channel_id", ch.ID, "channel_type", ch.Type)
			break
		}
		adaptor.Init(info)

		lastErr = relayAttempt(c, info, adaptor)
		if lastErr == nil {
			return
		}
		info.Request.LastError = lastErr

		logger.Warn("上游尝试失败",
			"request_id", info.Request.RequestID,
			"attempt", attempt,
			"channel_id", ch.ID,
			"model", info.Request.OriginModelName,
			"error", lastErr.Error())

		// ★ 客户端已经收到字节：不能再换渠道，否则会收到两段拼接的内容。
		if info.WroteResponse() {
			break
		}
		if !lastErr.Retryable {
			break
		}
		if lastErr.ChannelError {
			service.DisableChannel(ch.ID)
		}
	}

	if lastErr == nil {
		lastErr = types.NewNoChannelError(info.Request.OriginModelName)
	}
	if !info.WroteResponse() {
		lastErr.Write(c)
	}
}

// relayAttempt 是"一次尝试"：转换 → 发请求 → 处理响应。
func relayAttempt(c *gin.Context, info *relaycommon.RelayInfo, adaptor channel.Adaptor) *types.APIError {
	converted, err := adaptor.ConvertRequest(c, info, info.Request.Body)
	if err != nil {
		// 转换失败是请求本身的问题：重试同一个坏请求没有意义。
		return types.NewBadRequest("请求转换失败: " + err.Error())
	}

	resp, err := adaptor.DoRequest(c, info, bytes.NewReader(converted))
	if err != nil {
		// 客户端先断开时，上游请求会随 ctx 一起取消——这不是渠道故障。
		if c.Request.Context().Err() != nil {
			return types.NewClientGone()
		}
		return types.NewTransportError("请求上游失败: " + err.Error())
	}
	defer resp.Body.Close()

	info.Attempt.UpstreamStatus = resp.StatusCode
	_, apiErr := adaptor.DoResponse(c, resp, info)
	return apiErr
}

func readRequestBody(c *gin.Context) ([]byte, *types.APIError) {
	limited := http.MaxBytesReader(c.Writer, c.Request.Body, maxRequestBodyBytes)
	body, err := io.ReadAll(limited)
	if err != nil {
		var tooLarge *http.MaxBytesError
		if errors.As(err, &tooLarge) {
			return nil, types.NewRequestTooLarge()
		}
		return nil, types.NewBadRequest("读取请求体失败: " + err.Error())
	}
	return body, nil
}

// firstAPIKey 支持渠道里用逗号分隔多个 key（M4 才做轮询，M1 只用第一个）。
func firstAPIKey(keys string) string {
	for _, k := range strings.Split(keys, ",") {
		if k = strings.TrimSpace(k); k != "" {
			return k
		}
	}
	return ""
}

// modelAllowed 校验令牌的模型白名单。未启用白名单时一律允许。
func modelAllowed(auth *relaycommon.AuthInfo, modelName string) bool {
	if auth == nil || !auth.ModelLimitsEnabled {
		return true
	}
	allowed := parseModelLimits(auth.ModelLimits)
	if len(allowed) == 0 {
		// 开了白名单却没有有效条目：按"谁都不允许"处理（fail-closed）。
		return false
	}
	for _, m := range allowed {
		if m == modelName {
			return true
		}
	}
	return false
}

// parseModelLimits 同时接受 JSON 数组与逗号分隔两种历史写法。
func parseModelLimits(raw string) []string {
	raw = strings.TrimSpace(raw)
	if raw == "" {
		return nil
	}
	if strings.HasPrefix(raw, "[") {
		var arr []string
		if err := common.UnmarshalString(raw, &arr); err == nil {
			return arr
		}
	}
	parts := strings.Split(raw, ",")
	out := make([]string, 0, len(parts))
	for _, p := range parts {
		if p = strings.TrimSpace(p); p != "" {
			out = append(out, p)
		}
	}
	return out
}
```

```go
func runUser(args []string, out io.Writer) error {
	if len(args) < 2 || args[0] != "add" || args[1] == "" {
		return fmt.Errorf("用法: optctl user add <username> [<group>] [<quota>]\n%s", usage)
	}
	group, quota := "default", int64(0)
	if len(args) >= 3 && strings.TrimSpace(args[2]) != "" {
		group = strings.TrimSpace(args[2])
	}
	if len(args) >= 4 {
		n, err := strconv.ParseInt(args[3], 10, 64)
		if err != nil {
			return fmt.Errorf("quota 必须是整数: %w", err)
		}
		quota = n
	}

	u := model.User{
		Username:  args[1],
		Role:      constant.RoleUser,
		Status:    constant.UserStatusEnabled,
		GroupName: group,
		Quota:     quota,
	}

		return fmt.Errorf("创建用户失败: %w", err)
	}
	fmt.Fprintf(out, "user id=%d username=%s group=%s quota=%d\n", u.ID, u.Username, u.GroupName, u.Quota)
```
